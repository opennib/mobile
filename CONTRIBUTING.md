# Contributing to opennib mobile

Thanks for your interest in opennib — free, open-source, fully local
dictation.

**Where development happens:** opennib is currently developed in a private
monorepo (core + the desktop app + this mobile app) while the apps are
prepared for release. This repository mirrors the mobile app. That means:

- **Issues and discussion are very welcome here** — bug reports, device
  findings (especially Android, which is not yet stable), UX feedback.
- **Pull requests are hard for us to merge right now** — changes land in the
  private monorepo first and flow out with the next release. For anything
  larger than a typo, please open an issue first so the work isn't wasted.
- The full monorepo goes public as the project approaches v1.0, at which
  point normal PR flow opens up.

## Working on this app

Requirements: Node.js ≥ 22.17, npm, Xcode 15+ with CocoaPods for iOS,
Android Studio with an API 29+ device or emulator for Android. See
[`docs/setup.md`](docs/setup.md) for the generated-files dance that every
fresh clone needs before the first run.

```sh
npm install
npm run prebuild       # bare worker bundle + expo prebuild (ios/ + android/)
npm run typecheck      # tsc --noEmit
npm run ios            # build + run on the iOS simulator
npm run android        # build + run on an Android device/emulator
npm run format         # Prettier
```

There are no automated tests yet; CI runs typecheck, formatting, and the
Bare worker bundle.

## Ground rules for code in this repo

1. **No business logic in the app shell.** Screens, hooks and native modules
   translate between platform APIs and the interfaces declared by
   [`@opennib/core`](https://github.com/opennib/core). Decisions and
   orchestration belong in core or in the Bare worker (`bare/index.mjs`).
2. **Hermes never touches `@qvac/sdk` or Hypercore.** Both run inside the Bare
   worker; the React Native side speaks to it over the generated HRPC contract
   (`@opennib/core/hrpc`). If a feature needs a new command, it needs a
   contract change in core first.
3. **Typed errors, never silent catches.** Domain failures use the
   `OpennibError` subclasses from `@opennib/core`. Every `catch` re-throws,
   converts to a typed error, or carries a comment explaining why swallowing
   is correct.
4. **No `console.log`.** Use `log.info` / `log.warn` / `log.error` /
   `log.debug` from `@opennib/core`.
5. **TypeScript strict, no `any`.** Narrow from `unknown`. Named exports only.
6. **Never edit `ios/` or `android/`.** They are generated by `expo prebuild`
   from `app.json` and the config plugins in `plugins/`. Native code that
   must ship lives in `ios-keyboard/`, `ios-shared/`, `android-ime/` and is
   copied in by those plugins.
7. **Privacy is not negotiable.** No cloud calls, no telemetry, no
   third-party sync. Audio and transcripts stay on the device.

Commits follow [Conventional Commits](https://www.conventionalcommits.org/)
(`feat`, `fix`, `chore`, `refactor`, `docs`, `test`, `perf`, `build`).
